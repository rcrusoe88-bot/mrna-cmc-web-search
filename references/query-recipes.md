# Query Recipes

Use these recipes to search quickly without drifting into generic biotech or nanoparticle noise.

## 1. Latest signal scan queries

Use for broad monitoring.

```text
"mRNA CMC" latest
"mRNA IVT" latest
"mRNA-LNP" formulation latest
RNA manufacturing conference abstract analytical method
targeted LNP mRNA latest
mRNA stability assay latest
"in vivo CAR-T" latest
"in vivo cell engineering" latest
```

Add a year or conference name when needed.

## 2. Conference queries

Use official meeting names first.

```text
ASGCT mRNA delivery LNP
ISCT mRNA manufacturing analytical method
AAPS mRNA formulation stability
RNA Leaders USA mRNA manufacturing
ESGCT RNA delivery platform
AACR mRNA-LNP oncology delivery
ASGCT in vivo CAR-T
ESGCT in vivo cell engineering
```

Then search company pages around the same meeting:

```text
site:company-domain.com ASGCT mRNA
site:company-domain.com AAPS formulation
site:company-domain.com RNA Leaders manufacturing
```

## 3. Journal queries

Use platform plus problem statements.

```text
site:nature.com "mRNA-LNP"
site:science.org/journal/stm mRNA delivery
site:cell.com "Molecular Therapy" mRNA formulation
site:pubs.acs.org mRNA IVT impurity
site:nature.com/nbt RNA manufacturing
site:nature.com "in vivo CAR-T"
site:science.org/journal/stm "in vivo cell engineering"
```

## 5. Topic-shaping queries

Use these when the user needs a focused research angle rather than a broad bibliography.

```text
"mRNA IVT" bottleneck review
"mRNA-LNP" formulation challenge review
targeted LNP analytical method review
mRNA CMC bottleneck assay comparability
RNA manufacturing scale-up review
"in vivo CAR-T" bottleneck review
"in vivo cell engineering" platform review
```

## 6. Query construction rules

- Combine one modality term, one platform term, one process or assay term, and one development-stage or quality term.
- Use quotes for exact phrases such as `"mRNA-LNP"` and `"capping efficiency"`.
- Add site filters when generic search results become noisy.
- Add a date, year, or meeting name when the user wants the latest.
- Use both product language and technical language.
